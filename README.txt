WEBSITE ROMANTIS — POLAROID ANIMATION

Cara menjalankan:
1. Ekstrak folder website-romantis.
2. Buka index.html di browser, atau upload seluruh isi folder ke hosting.
3. Jangan pisahkan index.html, style.css, script.js, dan folder assets.

Edit tulisan/foto:
- Ganti gambar di folder assets (pertahankan nama file), atau ubah daftar memories di script.js.
- Ubah kalimat pada title dan sub di daftar memories dalam script.js.
- Atur warna, ukuran, dan animasi di style.css.

Website menggunakan HTML + CSS + JavaScript murni, tanpa framework.
